# Undo Only Selected

Undo or redo edits for selected text or lines without changing unrelated parts of the document. You can also undo or redo the line containing the cursor.

## Features

Commands are available from the Command Palette and editor context menu:

- **Undo Only Selected** and **Redo Selected Lines** operate on the selected range.
- **Undo Current Line** and **Redo Current Line** operate on the line containing the cursor.

On macOS, the default shortcuts use `Control+Command`; on Windows and Linux, they use `Control+Alt`. You can change them in Keyboard Shortcuts.
